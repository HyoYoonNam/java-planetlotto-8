# java-planetlotto-precourse
이 프로젝트는 콘솔 기반의 우테코 로또 발매기인 행성 로또를 구현하며, 프리코스에서 학습한 개발 방식(문제 분해, 설계, TDD)을 적용하는 것에 의의를 둔다.

## 구현할 기능 목록
아래에서 언급되는 '예외'는 `IllegalArgumentException`을 의미한다.

### 입력
- [x] 로또 구입 금액을 입력받는다.
- [x] 당첨 번호를 입력받는다.
- [x] 보너스 번호를 입력받는다.

### 로직
- [x] 로또 번호를 생성한다.
  - [x] 로또 번호는 범위(1~30 사이의 경계값을 포함한 정수) 내에서만 존재한다. 범위를 초과하는 로또 번호를 생성하려고 하면 예외를 발생한다.
  - [x] 로또 번호의 동일성은 번호로 판단한다.
- [x] 로또를 생성한다.
  - [x] 로또는 중복되지 않은 5개의 로또 번호로 구성된다.
    - [x] 중복된 로또 번호로 생성을 시도하면 예외를 발생한다.
    - [x] 가지는 로또 번호가 5개가 아닌 로또 생성을 시도하면 예외를 발생한다.
    - [x] 로또 번호의 범위를 벗어나는 숫자로 생성을 시도하면 예외를 발생한다.
- [x] 구입 금액만큼의 로또를 발행한다.
- - [x] 로또 구입 금액이 음수면 예외를 발생한다.
  - [x] 로또 구입 금액은 로또 1장의 가격(500원)으로 나누어떨어져야 한다. 그렇지 않으면 예외를 발생한다.
- [x] 당첨 번호를 추첨한다.
    - [x] 당첨 번호는 중복되지 않는 숫자 5개와 보너스 번호 1개를 가진다. 6개의 숫자는 모두 로또 번호이다.
        - [x] 당첨 번호를 구성하는 6개의 로또 번호 사이에 중복이 존재하면 예외를 발생한다.
- [x] 당첨을 계산한다.

### 출력
- [x] 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
- [x] 당첨 내역을 출력한다.

## 도전 과제
> 리팩터링: 시간 압박에 단위 테스트로 제대로 커버하지 못한 부분들을 커버하고, 여러 도메인에서 필요로 하는 상수에 대한 공통 상수화 등을 시도한다.
